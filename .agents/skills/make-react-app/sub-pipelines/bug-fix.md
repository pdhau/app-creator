# Bug Fix

1. Reproduce the bug with `user-flow-repro.md` when needed.
2. Trace the root cause across route, component, state/query, API, and persistence boundaries.
3. Write a failing regression test before changing implementation.
4. Fix the narrowest root cause and avoid unrelated refactors.
5. Run live iteration, the focused regression test, and the nearest broader check.
6. Update the milestone, `docs/STATE.md`, and backlog if follow-up risk remains.
