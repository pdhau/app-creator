# User Flow Reproduction

Use when a requirement or bug is too vague to test.

1. Identify route, account state, viewport, data fixture, and starting conditions.
2. Write exact user actions and the expected visible result after each action.
3. Capture actual result, console/network errors, and the smallest stable reproduction.
4. Convert the reproduction into an acceptance criterion and a failing regression test.
5. Attach screenshots or traces only when they clarify a visual or timing issue.
6. Return to the development pipeline with a checkable behavior.
