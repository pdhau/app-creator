# Scope Triage

1. Enumerate every requested feature, fix, polish item, refactor, and open question.
2. Read `docs/backlog.md` and avoid duplicate entries.
3. Choose one slice that balances user impact, dependency order, and one-session shippability.
4. Append every deferred item to the backlog with context and a suggested future milestone.
5. Confirm the chosen slice and its tradeoff with the user before coding.
6. Do not silently drop an item or bundle unrelated work.
