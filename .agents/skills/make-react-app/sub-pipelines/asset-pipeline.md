# Asset Pipeline

1. Define asset purpose, dimensions, formats, license, alt text, and responsive variants.
2. Inspect existing public/src/CDN conventions before adding files.
3. Validate uploads by type, size, dimensions, and content at the server boundary.
4. Optimize images, fonts, video, and icons; prevent layout shift with dimensions.
5. Lazy-load noncritical media and verify cache headers and production URLs.
6. Test missing, slow, transformed, and inaccessible asset states.
