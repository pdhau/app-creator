# React App Sub-pipelines

Use these focused workflows when the main phase pipeline calls for them.

- `session-start.md`: restore context and detect documentation drift.
- `scope-triage.md`: reduce multiple asks to one focused session and record the rest.
- `milestone-planning.md`: derive the next one to three delivery milestones.
- `user-flow-repro.md`: turn vague behavior into a reproducible, checkable flow.
- `live-iterate.md`: verify console, workflow state, screenshot, and user-visible behavior after edits.
- `bug-fix.md`: reproduce, write a regression test, repair root cause, and verify.
- `asset-pipeline.md`: add images, fonts, media, or uploads with performance and accessibility checks.
- `state-machine.md`: model complex async or multi-step UI states explicitly.
- `doc-drift-audit.md`: compare implementation, scripts, and docs and repair stale guidance.
- `agents-bootstrap.md`: generate `AGENTS.md` and `CLAUDE.md` from project sources.

Read the relevant file before starting that workflow. Keep the output in the project's `docs/` contract.
