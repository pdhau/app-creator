# Session Start

1. Read `docs/STATE.md` first when it exists.
2. Read `docs/product-plan.md`, `docs/tech.md`, active milestones, and `docs/backlog.md`.
3. Inspect git status, scripts, current route, and the nearest implementation surface.
4. Restore the active milestone, last verified behavior, blockers, and next concrete step.
5. If docs are missing or stale, run the minimum doc-backfill or `doc-drift-audit` before coding.
6. Confirm the session has one focused outcome; send extra asks to scope triage.
