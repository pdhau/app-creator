# Live Iterate

Run after every code change.

1. Start or reuse the development server and open the affected route.
2. Check browser console, failed requests, and runtime errors.
3. Exercise the exact workflow with normal and boundary data.
4. Verify URL, visible state, focus, responsive layout, and persistence where relevant.
5. Capture a screenshot for visual changes and compare the intended hierarchy.
6. Record the command and result in the milestone or state handoff.

A passing build does not replace this browser verification.
