# Documentation Templates

Copy these structures rather than inventing new shapes:

- `product-plan.md`: users, outcome, workflows, scope, and success criteria.
- `tech.md`: stack, scripts, runtime configuration, boundaries, and constraints.
- `milestone.md`: objective, scope, dependencies, acceptance criteria, exit condition, evidence.
- `adr.md`: decision, context, options, consequences, and status.
- `backlog.md`: append-only deferred or rejected work.
- `state.md`: current milestone, last action, blockers, and next step.
- `agents.md`: generated cross-tool project rules.

Consistent docs are part of the implementation, not release decoration.
