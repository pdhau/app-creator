# Useful React Skills

Select only the neighboring workflow needed for the current task.

- `quick-react-prototype`: validate one workflow quickly.
- `use-react-template`: bootstrap a repository using an existing React template.
- `react-architecture`: decide boundaries, state, routing, and services.
- `add-react-feature`: implement a vertical feature slice.
- `design-react-ui` or `product-design`: improve interaction and visual direction.
- `add-web-qa` or `web-qa`: add or run browser and accessibility coverage.
- `review-react-app` and `improve-react-app`: audit or implement improvements.
- `web-deploy` and `ship-react-app`: validate and release.
- `add-realtime`, `scaffold-entitlements`, and `monetize-web-app`: add optional product systems.
- `manage-web-assets` and `web-asset-pipeline`: handle media and uploads.
- `react-canvas`, `react-three`, and `webgl-performance`: optional visual computing paths.

Do not load optional skills merely because they exist; choose them from the user's requested outcome.
