# Idea Phase Pipeline

Use this phase when the product idea, users, or primary workflow is still unclear.

1. Clarify the user, job, desired outcome, constraints, and success signal.
2. Map the primary workflow from entry point to successful result.
3. List states, permissions, data needed, integrations, risks, and non-goals.
4. Compare only the stack options that affect delivery; prefer the repository's React/TypeScript conventions.
5. Write `docs/product-plan.md`, `docs/tech.md`, and `docs/architectural-decisions/0001-stack-and-boundaries.md` from the templates.
6. Ask the user to confirm the primary workflow and the first milestone before scaffolding.

Completion: the product outcome is concrete, the first workflow is checkable, and stack boundaries are recorded.
